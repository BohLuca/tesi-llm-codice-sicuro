REASON: The `data` variable is read directly from `System.in` via `BufferedReader.readLine()` without any validation, sanitisation, or allowlisting. It is then concatenated straight into the SQL string `"select * from users where name='"+data+"'"` and executed through `Statement.executeQuery()`. An attacker can inject a quote and arbitrary SQL clauses; a `PreparedStatement` with a bound parameter would be required to prevent this.
