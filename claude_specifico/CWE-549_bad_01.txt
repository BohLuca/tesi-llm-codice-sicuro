VERDICT: VULNERABLE

REASON: The password input field is declared as `type="text"` instead of `type="password"`, so the entered credential is rendered in cleartext on screen. This allows shoulder-surfing and exposes the password in screenshots or screen-sharing sessions, which is exactly CWE-549 (Missing Password Field Masking). Changing the input to `<input name="password" type="password" />` resolves it.
